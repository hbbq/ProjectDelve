# Red Dragon production miniature

Canonical Type: `red-dragon-type`, logical footprint 2x2.

The original Tripo Pro GLB is preserved byte-for-byte in `original.glb`.
The prepared runtime is `ProjectDelve.Web/wwwroot/art/models/units/red-dragon/v1/red-dragon.glb`.
See `provenance.json` for hashes, rights basis, validation and visual evidence.

Height is 1.45 Cells; actual radius 1.196189, allowed radius 1.20; circular base
radius .90. Low-tail/contact-envelope overhang is advisory. Geometry is not
shrunk, cropped or distorted to fit the base. Preparation uses the existing
pipeline, a reviewed rigid +90 degree Y wrapper, and three 1024 PNG textures.

Production Move and Attack facing established the final orientation. The first
-90 degree diagnostic export faced backwards and was replaced before approval.

See `../../FINAL_SIX_IMPORT.md` for the completion report and limitations.
