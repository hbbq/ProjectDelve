# royal-knight miniature

Mounted royal rider and real horse, intact rearing pose. Rear hooves sit on the base; lifted forelegs, head and plume overhang without exceeding the radius. Source -X forward corrected by rigid +90 degree Y scene wrapper; no geometry buffers or size changed. Initial support inspection-Tkfga6; corrected positive-Z Move inspection-5XRsZ0.

Original and runtime hashes, references, paid Pro evidence, validation and exact preparation settings are in [provenance.json](provenance.json). Original bytes are preserved unchanged. Runtime maps are limited to 1024; all three channels remain.

Reproduce with `node tools/prepare-unit-model.cjs assets/source/models/units/royal-knight/provenance.json --check`. See [final-six report](../../FINAL_SIX_IMPORT.md) for the complete preflight, import decisions, browser evidence and verification.
